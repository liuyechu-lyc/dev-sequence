# 实施记录

## 基线与范围

需求/原型/方案/任务修订，仓库位置、提交或快照，已有无关改动与复用范围。

## 任务证据

任务源使用技术阶段的 tasks.json，小修改可用等价简短任务说明。每项记录状态、实际产物、执行结果和证据；历史任务不重编号。

## 设计偏离与需求问题

来源 ID、发现、决策、回写位置和变更影响，不默默改规则。

## 实际检查结果

命令/方法、环境、版本、结果、证据及未执行原因。Mock和真实集成分开。

## 收敛与剩余工作

missing/partial/contradicts/unrequested、来源、证据、严重度及修复任务。不要把 Converged 当作实际测试通过。

## 运行与交付

启动、配置、迁移/部署说明、已知限制、独立代码评审及确认记录链接。
