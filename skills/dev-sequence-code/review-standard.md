# 代码编写验收规则

适用范围：本期已声明产物及其必要基线。保留项目特殊标准；不适用逐项说明理由。

| 检查ID | 验收标准 |
|---|---|
| CODE-01 | 代码/构建基线、任务和 FR/规则/AC 关联可定位，任务勾选均有实现/验证证据。 |
| CODE-02 | 业务、权限、数据状态和异常恢复符合需求；架构偏离有决策且已回写。 |
| CODE-03 | 适用输入校验、幂等、并发、重试/取消/补偿及真实数据一致性已检查。 |
| CODE-04 | 已约定构建、静态和相关测试实际运行，行为与关键不变量有证据，模拟与真实集成分开。 |
| CODE-05 | 按风险检查越权、注入、敏感信息、凭据、依赖和运行配置；必要部署/回退说明可用。 |
| CODE-06 | 规格收敛检查区分遗漏、部分实现、矛盾和超范围新增，有来源的修复任务不重复不重编号。 |
| CODE-07 | 独立评审、复验和实施确认绑定当前快照，无未解决阻塞问题，已知限制明确。 |

## 共通通过条件

当前版本/指纹有效，清单逐项有实际证据，没有未解决或仅已修复未复验的阻塞问题。MD与HTML同源，原始报告不可覆盖。独立评审与用户阶段确认分开；正式豁免不显示全部通过。所有报告/请求/提示词存项目根验收记录目录。

## 项目补充规则

执行者据真实范围补充，不以模板默认条目代替本期检查清单；源规则变化须刷新受影响旧验收。
