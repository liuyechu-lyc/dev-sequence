# 产品需求规划验收规则

适用范围：本期已声明产物及其必要基线。保留项目特殊标准；不适用逐项说明理由。

| 检查ID | 验收标准 |
|---|---|
| PRD-01 | 目标、用户、场景、证据、范围、排除和优先级理由明确；事实与假设分开。 |
| PRD-02 | 角色权限、数据归属、字段、对象关系、状态变化、异常与恢复足以执行且自洽。 |
| PRD-03 | 本期功能关联可复现 AC，覆盖关键正常、异常与边界，且核对真实业务结果。 |
| PRD-04 | 非功能目标、外部依赖、观测与发布约束按项目定义，指标未知时有测量/决策计划。 |
| PRD-05 | 当前正文、独立变更记录、版本和追溯一致；阻塞待决已解决，其他问题有影响和处理计划。 |
| PRD-06 | 产品含 AI 时能力、权限、输出、接管和评测要求完整；普通产品不强套 AI 条款。 |

## 共通通过条件

当前版本/指纹有效，清单逐项有实际证据，没有未解决或仅已修复未复验的阻塞问题。MD与HTML同源，原始报告不可覆盖。独立评审与用户阶段确认分开；正式豁免不显示全部通过。所有报告/请求/提示词存项目根验收记录目录。

## 项目补充规则

执行者据真实范围补充，不以模板默认条目代替本期检查清单；源规则变化须刷新受影响旧验收。
