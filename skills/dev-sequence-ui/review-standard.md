# UI设计验收规则

适用范围：本期已声明产物及其必要基线。保留项目特殊标准；不适用逐项说明理由。

| 检查ID | 验收标准 |
|---|---|
| UI-01 | 参考实际可查，来源、终端、观察时间、采纳范围及推断项明确。 |
| UI-02 | 风格方向已形成可查看代表性页面，有真实方向确认依据。 |
| UI-03 | 颜色、字体、间距、密度、布局、断点和组件规则可复用，与品牌/组件库关系明确。 |
| UI-04 | 适用组件覆盖关键视觉状态，真实终端上布局和可读性有效。 |
| UI-05 | 按项目要求检查对比度、焦点、键盘和无障碍，不能只凭视觉印象。 |
| UI-06 | 独立验收与规范版本确认分开记录，绑定可查看成果；未确认不自动成为风格基线。 |

## 共通通过条件

当前版本/指纹有效，清单逐项有实际证据，没有未解决或仅已修复未复验的阻塞问题。MD与HTML同源，原始报告不可覆盖。独立评审与用户阶段确认分开；正式豁免不显示全部通过。所有报告/请求/提示词存项目根验收记录目录。

## 项目补充规则

执行者据真实范围补充，不以模板默认条目代替本期检查清单；源规则变化须刷新受影响旧验收。
