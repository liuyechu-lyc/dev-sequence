# UI 设计规范

## 基线与参考

目标用户、使用场景、支持终端、品牌/组件库、参考清单及已确认方向。记录来源、观察时间、采纳/舍弃和推断项。

## 方向确认

代表性页面入口、版本、选择、确认人及真实依据。必要时比较少量实质不同方案。

## 设计令牌

颜色语义、字体/字号/行高、间距、圆角、阴影、密度；以 tokens.css 为实际源。业务令牌不覆盖原型查看器保留的 ds-* 令牌。

## 布局与终端

网格、容器、断点、导航、信息密度和响应行为；不以缩放代替响应式。

## 组件与状态

适用按钮/表单/表格/导航/弹窗等，默认、悬停、聚焦、禁用、加载及错误状态。

## 可读性与无障碍

声明终端上的实测结果、对比度、焦点、键盘及项目要求的其他检查；无法验证明确列出。

## 规范确认与复用

最终预览、令牌版本、适用范围、独立验收、用户/授权决策人确认及后续变更影响。
