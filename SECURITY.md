# Security / 安全问题

This project contains local workflow instructions and Python tools. Project permissions and the host's isolation capabilities remain part of the execution environment.

For a suspected vulnerability, use GitHub's **Report a vulnerability** option in the repository's Security tab when available. If private reporting is unavailable, open an issue requesting a private reporting channel without including the exploit, credentials, or affected private data. There is no guaranteed response time.

General bugs can be reported through ordinary issues with sanitized reproduction details.

## 中文

发现疑似安全漏洞时，优先使用仓库 Security 页面的 **Report a vulnerability** 私密反馈入口。如该入口不可用，可先开 issue 请求私密沟通渠道，不要公开漏洞利用步骤、密钥或私有数据。普通问题请提交脱敏后的复现资料；当前不承诺固定响应时间。
